# 与本机完整 `code-review-test` 的衔接

本公开包内的 `java-change-review` 可独立运行方案与代码审查。某些环境还安装了更完整的测试视角 `code-review-test`；它包含独立的范围解析、测试确认、报告与平台扩展。**仅当目标环境确实有这套 Skill 且项目允许使用时**才调用，不能从本公开包假定其依赖或权限存在。

交接时提供：被审仓库绝对路径、明确的 PR/MR 或 base/target SHA、需求与技术方案版本、期望阶段、当前已验证事实、已否定候选、自测证据与未覆盖项。让它按实际安装版本的 `SKILL.md` 解析范围和执行；不要把本包的轻量脚本输出冒充其正式 Scope Manifest。

推荐分工：

| 节点 | 本包 | 完整测试视角 Skill（可用时） |
| --- | --- | --- |
| 编码前 | 审最小方案与过度设计 | 有适用能力时核对需求/设计与可测性 |
| 开发中 | 审当前 diff、修明显回归 | 按其阶段选择做更广的候选发现与独立确认 |
| 提测前 | 汇总已验证路径和剩余风险 | 根据上下游证据给回归范围与测试资产交接 |

完整 Skill 的缺陷提报、TEST 环境执行、四层证据和远端操作各有额外依赖与授权。只想先得到本地 CR 时，明确“只本地分析，不提报、不提交、不推送”。不要为了安装它而复制公司源码、内部配置或作者个人授权到公开包。
